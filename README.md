# Studio — Research, Knowledge & Thinking Platform

A unified master workspace for knowledge work:
- 🏠 **Home**: Omni-Search (`⌘K`), reading shelves, and recent canvases.
- 📖 **Books & EPUB Reader**: Offline IndexedDB storage, chapter flow, text highlighting, and annotation notes.
- 📰 **Articles & Papers**: Archival, external link opening, reading queue, and canvas quotes.
- 🔬 **Research Whiteboard**: Smooth 60fps canvas, geometric shapes/symbols, sticky notes, connector arrows, and in-canvas live browsers.
- 📊 **Dashboard**: Topic metrics and cross-canvas relationships.
- ☁️ **Supabase Cloud Sync**: 1-click cloud snapshot backup & restore.

---

## 🚀 One-Click Deployments

### Deploy to Vercel
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and import this repository.
3. Click **Deploy** (zero configuration required!).

Or via Vercel CLI:
```bash
npx vercel
```

---

### Deploy to Firebase Hosting
1. Install Firebase CLI:
   ```bash
   npm install -g firebase-tools
   ```
2. Log in and initialize:
   ```bash
   firebase login
   firebase init hosting
   ```
3. Deploy:
   ```bash
   firebase deploy
   ```
